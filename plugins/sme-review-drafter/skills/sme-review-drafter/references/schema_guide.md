# 검토의견 JSON 필드 설명

`assets/opinion_template.json` 과 같은 구조. 모든 필드는 필수이며 값이 없으면 빈 문자열/빈 목록.

## ReviewOpinion
검토의견서 전체.

| 필드 | 타입 | 설명 |
|---|---|---|
| `overview` | <class 'Overview'> |  |
| `extra_info` | <class 'ExtraInfo'> |  |
| `summary` | <class 'VerdictSummary'> |  |
| `similar_programs` | list[SimilarProgram] | 유사중복 사업이 없으면 빈 목록 |
| `validity` | <class 'AxisOpinion'> | ○ (사업 타당성) |
| `suitability` | <class 'AxisOpinion'> | ○ (사업 적합성) |
| `content_box` | <class 'ContentBox'> |  |
| `check_box` | <class 'CheckBox'> |  |
| `duplication` | <class 'AxisOpinion'> | ○ (유사·중복성) |
| `improvements` | list[Improvement] | 개선의견. 전 항목 동의이면 headline '해당 없음' 1건 |
| `comparison` | <class 'ComparisonTable'> |  |
| `similarity` | <class 'SimilarityReport'> | 유사도 분석 결과(선택). 비교표의 기존사업은 상위 3개 후보를 토대로 선정 |
| `reviewer_notes` | list[str] | 검토자가 확인해야 할 불확실 사항·가정. 문서 본문에는 출력하지 않고 별도 메모로 제공 |

## Overview
□ 협의신청사업 개요 표.

| 필드 | 타입 | 설명 |
|---|---|---|
| `사업명` | <class 'str'> | 예: '184. 투·융자연계형 연구개발지원 사업 / 세부신설'. 협의번호를 모르면 사업명 / 요청사유만 기재 |
| `신청기관` | <class 'str'> | 예: '부산광역시 연구개발과'. 담당자 성명·연락처는 기재하지 않음 |
| `지원유형` | <class 'str'> | 예: '육성 / 기술 / 중소기업, (예비)창업기업 / 전업종 / ’27년 예산 1,000백만원' |
| `특이사항` | <class 'str'> | 사후협의·시범사업 후속·이전 협의 이력 등. 없으면 '해당 없음' |
| `검토자` | <class 'str'> | 검토자 성명·직위. 입력이 없으면 빈 문자열 |

## AxisOpinion
○ 평가축 항목 (사업 타당성 / 사업 적합성 / 유사·중복성).

| 필드 | 타입 | 설명 |
|---|---|---|
| `headline` | <class 'str'> | '(사업 타당성) 법적근거 및 정책수요 측면 타당, “원안 동의”' 형식. 앞의 '○ ' 는 붙이지 않음 |
| `group_labels` | list[str] | 유사·중복성에서 내역사업별로 dash 를 묶을 때 쓰는 소제목. 예: ['➊ 중장년 재도전 프로그램 운영', '➋ 대·중견기업 연계 밋업']. 사용하지 않으면 빈 목록 |
| `dashes` | list[Dash] |  |
| `dash_groups` | list[list[Dash]] | group_labels 를 쓰는 경우 소제목별 dash 묶음. group_labels 와 길이가 같아야 하며, 이때 dashes 는 비워 둠 |
| `remarks` | list[str] | '※' 비고 줄. 예: 유사중복 자체점검표 미작성 지적 |

## Dash
'-' 항목: 검토자의 평가·판단 진술 (사실 압축 + 판단어휘).

| 필드 | 타입 | 설명 |
|---|---|---|
| `label` | <class 'str'> | 괄호 라벨. 예: '사업성격', '법적근거·상위정책', '정책수요', '사업성과', '지원내용', '지원규모', '수행체계', '사업목적', '지원대상', '지원방식'. 라벨이 없으면 빈 문자열 |
| `text` | <class 'str'> | 본문. 각주를 가리키는 '*', '**' 표시를 포함할 수 있음. 문장 끝 마침표 없음 |
| `notes` | list[str] | '*' 각주 줄. 예: '(법적근거) 「…조례」 제17조'. 두 번째 각주는 '**' 로 시작하도록 텍스트 앞에 '** ' 를 붙이지 말고 순서로만 구분 |

## ComparisonTable
사업간 비교표.

| 필드 | 타입 | 설명 |
|---|---|---|
| `columns` | list[str] | 첫 열 제목(구분)을 제외한 열 제목. 예: ['(신규사업) 소상공인 인력 운영 지원', '(기존) 기업인력애로센터 활용 취업 지원'] |
| `rows` | list[list[str]] | 각 행은 [구분, 값1, 값2, …]. 구분 순서: 사업부서, 사업구조, 사업기간, 지원예산, 사업목적, 수행기관, 지원내용, 지원규모, 지원대상. 셀 내 줄바꿈은 '\n' |
