# 산출 방법론

## 1. 왜 임베딩인가

유사·중복 검토의 1차 선별은 "서술이 얼마나 가까운가"의 문제다. 키워드 일치는 표기 차이(핀테크/금융혁신, 실증/테스트베드)에
약하고, 분류코드 일치는 같은 중분류 안의 수백 건을 구분하지 못한다. 다국어 문장 임베딩(BAAI/bge-m3)은 두 서술의 의미적
근접성을 0~1 코사인 값으로 주므로, 축별로 따로 재어 지표(안)의 가중치로 합치면 지표 체계와 1:1로 대응하는 점수가 나온다.

## 2. 축별 텍스트 구성

같은 축끼리 비교해야 의미가 있으므로 신규사업과 기존사업 모두 네 문장을 따로 만든다.

| 축 | 신규사업(프로필) | 공고정보(xlsx) | 내역사업(biz) | 내내역(biz_struct) |
|---|---|---|---|---|
| 사업목적 | 목적·필요성·근거·성과지표 | ①목적 + 정책목적 태그 | 내역목적(없으면 세부목적) | 부모 내역사업 상속 |
| 지원대상 | 대상 기업·개인·참여기관 | ③대상 + 대상유형·업종 | 수혜대상 + 지원산업 | 부모 상속 |
| 지원내용 | 내역사업별 지원 메뉴·규모 | ②내용 + ④규모 + ⑤설명 | 세부목적 / (내역) 내역목적 + 공고 지원내용 + 세부내용 + 산출근거 | (내내역) 항목명·예산 + 산출근거 중 해당 문장 + 부모 내역 서술 |
| 전달체계 | 주관 → 수행기관, 시행방법, 지원방식 | 주관부처 → 수행기관(직접수행 여부), 지원유형 대/중분류, 지원방식 키워드, 규모 | 소관 → 세부추진기관, 세부지원(직접/출연/보조…), 지원분야, 지원방식 키워드 | 부모 상속 |

지원방식 키워드는 본문에서 바우처·보조금·출연·융자·보증·투자·교육·인턴십·채용연계·실증·매칭·컨설팅·멘토링·공모·자격취득·위탁·플랫폼·인건비·장려금을 찾아 붙인다. 공고문에는 시행방법이 없어서 이 근사가 필요하다.

공고정보가 보강 자료로 붙은 단위는 해당 축 끝에 `[공고 목적] …`, `[공고 <이름>] … 규모: …`, `[공고 대상] …`이 덧붙는다.

## 3. 가중치

「유사·중복사업 대상 선정 분석 지표(안)」 기본항목: 사업목적 20, 지원내용 30, 지원대상 30, 전달체계 15 (합 95).
합 100으로 비례 조정하면 21.05 / 31.58 / 31.58 / 15.79. 종합 유사도 = Σ 가중치 × 코사인.

5단계 배점(상이→동일)은 지표(안)의 점수열(목적 0/5/10/15/20, 내용·대상 0/6/14/22/30, 전달 0/3/7/11/15)을 축 가중치 비율로
환산한다. 등급 경계는 축별 코사인의 코퍼스 내 z-점수 0/1/2/3이다. 절대 임계값이 아니라 상대 기준이므로 코퍼스가
바뀌면 같은 사업의 등급이 달라질 수 있다. 그래서 순위 근거는 종합 유사도이고 등급·환산점수는 참고치다.

## 4. 기존사업 단위 규칙

- 기본 단위는 내역사업. 공고는 단위가 아니다(같은 사업이 공고 수만큼 후보를 차지하는 왜곡 방지).
- 사업목적이 없는 행은 제외한다(임베딩할 서술이 없다).
- 같은 (구분, 소관, 세부사업명, 내역사업명)이 2025·2026년에 모두 있으면 최신 연도만 남긴다. 공백·기호 차이는 무시한다.
- biz_struct 레벨3·4 항목이 있는 내역사업은 내내역 단위로 대체한다. 부모는 제거한다(부모와 자식이 함께 있으면 서로 중복 후보가 된다).
  레벨4는 레벨3의 내용에 "세부항목: …"으로 덧붙인다.
- 내내역의 지원내용은 "(내내역) 항목명, 예산" + 부모 산출근거 중 항목명을 포함하는 줄 + 부모 내역 서술로 만든다. 산출근거 전체 텍스트는
  `parents_full` 추출본을 쓴다(기본 추출은 300자로 잘려 있다).
- 내내역 부모 중 센터운영·조사연구 등은 biz(중소기업 지원사업 DB)에 없으므로 매칭되지 않는 것이 정상이다.

## 5. 공고명 ↔ 단위 매핑

xlsx의 공고이름은 편집된 짧은 이름이고 gonggo 표의 공고명은 실제 공고 제목("… 참여기업 모집 공고")이라 정확 일치가 거의 없다.
세 단계로 연결한다.

1. gonggo 공고명과 글자 2-gram Dice 계수 대조(연도 가점 0.05, 부처 약칭↔정식명 부분수열 일치 필수, 임계 0.6) → 해당 (소관, 세부, 내역) 단위
2. 공고명 머리(괄호 앞)가 세부사업명과 거의 같으면(Dice 0.8) 괄호 안 어절이 내역·내내역의 사업명(가중 3)·목적(2)·내용(1)에 나타나는 단위를 고른다. 동점이면 모두에 붙인다.
3. 단위명(세부+내역+내내역 / 내역+내내역)과 직접 대조(임계 0.6)

연결 결과와 점수는 xlsx `공고매핑` 시트에 남는다. 미연결 공고는 보강에서 빠질 뿐 분석을 막지 않는다.

## 6. 결과 해석 기준

- 상위 10개가 평균+2σ 또는 상위 1% 기준선 위에 있으면 "후보가 분포의 꼬리에 있다"고 말할 수 있다. 기준선 아래 후보는 유사성이 약하다고 적는다.
- 상위권 내부 간격(2점 이상)은 직접 중복 검토/연계 검토의 경계로 쓴다.
- 동일 세부사업의 단위가 여럿이면 세부사업 단위로 묶어 판단하라고 적는다.
- 전달체계 축은 수행기관 근사 때문에 같은 기관 사업이 체계적으로 높다. 지원내용 축 값을 함께 제시해 보정한다.
