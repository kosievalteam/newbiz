# 보고서 틀과 문체

파일명: `유사중복_검토_<사업 약칭>.md`. 머리에 협의사업 식별(부처·과, 연도, 예산, 수행기관), 분석일·도구, 산출파일 경로를 세 줄로 둔다.

## 구조

```
# 「<사업명>」 사업 유사·중복 후보 분석 결과

## 1. 검토 개요
□ <무엇을 무엇과 어떻게 비교해 몇 개를 선정했는지 한 문장>
 ○ (협의사업 자료) 기본/보조 자료와 단위 구성
  - 내역사업 단위 분리 내용
  * 축 서술 예시 한 줄
 ○ (기존사업 단위) 자료원, 건수, 제외·중복 처리, 내역/내내역 구성
  - 건수 수치
  * 내내역 분리 예
 ○ (공고정보 처리) 보강 자료로 쓴 방식, 매핑 건수
  * 대표 연결 예
 ○ (산출 방법) 코사인 → 가중합, 가중치 조정
  | 가중치 표 |
  - 등급은 참고치라는 문장

## 2. 분석 결과: 유사·중복 검토 후보 10개
□ <후보 구성(유형별 건수)과 분포상 위치>
 ○ (분포) 평균·표준편차, 기준선과 후보의 관계, 상위권 간격
 | 순위 | 기존사업 단위(부처·수행기관) | 단위 | 종합 유사도 | 사업목적 | 지원내용 | 지원대상 | 전달체계 | 지표(안) 환산점수 |
 ○ (유형 1) 핵심 검토사항 한 문장
  - 사업별 사실(지원내용·대상·규모)과 겹치는 지점
  * 중복수혜가 생기는 구체 구조
 ○ (유형 2) …
 ○ (단위·자료 변경 효과) 이전 분석 대비 달라진 점(있을 때)

## 3. 내역사업별 후보 (참고)
□ <내역사업별 상위 유형 요약>
 ○ (내역사업 ①) 상위 5개와 점수
  - 자체점검표·설명자료가 든 비교 사업의 실제 순위
 ○ (내역사업 ②) …

## 4. 유의사항
□ 선별 지표이지 중복 판정이 아니라는 문장
 ○ (단위 특성) 내내역 상속, 연도 통합, 지원규모 값의 의미
 ○ (공고 연결) 자동 연결의 한계, 풀에 없는 사업 유형
 ○ (지표 특성) 전달체계 축 편향과 보정 해석
 ○ (등급 활용) 참고치, 재산출 방법·자료 취급
```

## 문체 규칙

- 개조식 위계: □는 그것만 읽어도 결론이 서는 문장, ○는 □의 구체 내용, -는 ○의 부연·수치, *는 구체 예시. 한 수준에서 다른 수준의 역할을 하지 않는다.
- 문어체, 명사형 종결("…필요", "…존재", "…해당"). 구어체·추측형("~것 같다") 금지.
- 한 문장 한 주장. 같은 사실을 다른 수준에서 반복하지 않는다.
- 수치는 소수 첫째 자리까지(유사도), 건수는 정수, 금액은 백만원 단위 천 단위 구분.
- 사업명은 「」로 묶고 부처·수행기관을 괄호로 붙인다. 내역·내내역은 "세부 > 내역 > 내내역"으로 쓴다.
- 판단 어휘는 "검토 필요", "검토 대상", "연계 검토", "확인 필요"로 끝낸다. "중복이다"로 단정하지 않는다.

## 작성 후 점검 체크리스트

1. 본문의 모든 순위·점수·건수를 xlsx에서 다시 읽어 일치하는가. 전칭 서술("모두 넘는다")은 실제 건수로 확인했는가.
2. 가중치 표의 합이 100.00인가. 배점 환산열이 가중치와 맞는가.
3. 후보 표의 10개와 본문 ○ 항목의 설명이 빠짐없이 대응하는가.
4. 자체점검표·설명자료가 언급한 비교 사업의 순위를 적었는가.
5. 같은 세부사업의 단위가 여럿이면 "실제 사업 수는 더 적다"고 적었는가.
6. 유의사항에 자료 범위(미반영 자료, 풀에 없는 유형)와 지표 한계가 있는가.
7. 추출 원본 자료를 커밋하지 않았는가. 보고서에 담당자 성명·연락처가 들어가지 않았는가.
